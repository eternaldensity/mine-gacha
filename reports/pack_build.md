## What the lock guarantees, and what it does not

- Guarantees: every declared milestone A project resolves to one concrete build, its file is identified by sha1 and sha512, and the archive is a pure function of the manifest plus the cache.
- Does not guarantee: that the set co-loads. A boot test needs a JVM and the NeoForge installer, neither of which is available offline here; the runtime harness records that as an external prerequisite instead of claiming a smoke test that never ran.
